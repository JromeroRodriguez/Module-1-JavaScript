# Rick & Morty Character Archive 🧪🛸

Este es un proyecto web que utiliza la **API de Rick and Morty** para mostrar una galería interactiva de los personajes de la serie. Permite explorar los personajes con paginación, filtrarlos por género y ofrece una experiencia de usuario fluida con indicadores de carga.

## 🚀 Características

- **Consumo de API:** Uso de `Axios` para peticiones asíncronas a `https://rickandmortyapi.com/api/character`.
- **Paginación Dinámica:** Botones de "Anterior" y "Siguiente" para navegar a través de todas las páginas de personajes.
- **Filtrado:** Capacidad para filtrar personajes por género (Male, Female, Unknown) en tiempo real.
- **Interfaz Moderna:** Diseño temático con fuentes personalizadas (*Orbitron* para títulos y *Inter* para lectura).
- **Indicador de Carga:** Feedback visual mientras se obtienen los datos de la API.
- **Responsive Design:** Adaptado para diferentes tamaños de pantalla.

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Estructura semántica.
- **CSS3:** Estilos personalizados, incluyendo animaciones y Flexbox.
- **JavaScript (ES6+):** Lógica de filtrado, manejo de promesas y manipulación del DOM.
- **Axios:** Cliente HTTP para las peticiones a la API.
- **Google Fonts:** Tipografía *Orbitron* e *Inter*.
